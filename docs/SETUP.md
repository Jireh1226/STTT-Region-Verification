# Setup and reproduction

## Review without installing a solver

From the repository root:

```sh
python3 summarize_saved_results.py
python3 check_artifact.py
```

These commands read the included results. They do not download datasets, run inference, train a model, or rerun solver queries.

## Prepare an experiment environment

The research scripts target Python 3.11. Create the environment inside `artifact/`, because several scripts expect the Marabou executable at `artifact/prophecy_env/bin/Marabou`:

```sh
cd artifact
python3.11 -m venv prophecy_env
source prophecy_env/bin/activate
python -m pip install numpy h5py scipy matplotlib
python -m pip install maraboupy
```

The manuscript uses Marabou 2.0. Install that solver version for a historical reproduction and record the versions actually used. Follow the [official Marabou installation instructions](https://github.com/NeuralNetworkVerification/Marabou) for the Python bindings and command-line executable. Some experiments invoke the executable directly; confirm it exists at the path above before running those scripts. A Python binding installation alone should not be assumed to supply that executable.

Different experiment families need additional libraries:

| Experiment | Additional dependencies or assets |
| --- | --- |
| TinyTaxiNet empirical analysis | VerifyGAN model and HDF5 data |
| New solver queries | Marabou 2.0 bindings; CLI for scripts that invoke it |
| Autoencoder and compact MNIST training/export | TensorFlow, tf2onnx, ONNX, model-specific data |
| External MNIST network | ONNX Runtime, VNN-COMP model and MNIST data |
| LARD preparation and training | Pillow, PyTorch, LARD V2 imagery |

Use separate environments when training-library requirements conflict. The saved-results commands above do not depend on these libraries.

## External assets

Obtain the TinyTaxiNet network and data from [SISL VerifyGAN](https://github.com/sisl/VerifyGAN). The scripts expect these paths beneath `artifact/`:

```text
VerifyGAN/models/TinyTaxiNet.nnet
VerifyGAN/data/SK_DownsampledGANFocusAreaData.h5
```

The optional activation-pattern experiment uses [SRI-CSL Prophecy](https://github.com/SRI-CSL/prophecy-papers). External benchmark setup is implemented in `prepare_vnnlib_calibration_assets.py`; LARD download and preprocessing are implemented in `prepare_external_lard_dataset.py`. The LARD source is [DEEL-AI/LARD_V2](https://huggingface.co/datasets/DEEL-AI/LARD_V2). These assets are obtained separately; this repository contains scripts, records, plots, and manuscript files.

## Entry points

Run research commands from `artifact/` in a working copy, because they write result files:

```sh
make PY=./prophecy_env/bin/python reproduce-empirical
make PY=./prophecy_env/bin/python reproduce-solver
```

The original [research README](../artifact/README.md) describes further targets. Some targets depend on models generated by earlier training scripts, so first inspect the requirements of the chosen experiment. The [results map](../RESULTS_AND_CODE.md) links each main finding to its precise script and saved output, including PCA sweeps, random-direction controls, and external-model tests.

## Manuscript

The complete PDF is `manuscript/paper.pdf`. Its source is `manuscript/paper.tex`, with figures and LaTeX support files alongside it. Use a LaTeX installation with the packages named in the source if rebuilding the paper. The manuscript is the revised unpublished draft used in the graduation portfolio.
