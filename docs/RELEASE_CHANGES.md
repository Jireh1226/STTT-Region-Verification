# Changes for the standalone repository

Prepared November 8, 2026 from the preserved STTT manuscript and research package.

- Added the repository README, requirements, design, setup, validation, and attribution documents.
- Added a standard-library release checker, file manifest, and Git exclusions.
- Changed `_inspect_net.py` to resolve its own directory instead of a machine-specific absolute path.
- Corrected the historical research README's manuscript status and description of external assets included in this standalone package.
- Preserved the numerical result files and manuscript PDF byte for byte.

`SOURCE_MANIFEST.json` records original source hashes and release hashes for the selected research files. `RELEASE_MANIFEST.json` records every distributed file except itself. The manuscript is unpublished; STTT identifies its intended journal, not an acceptance or publication.

The public repository was initialized by the author with an MIT license. That license is retained in this release, and the README and attribution document reflect it.
